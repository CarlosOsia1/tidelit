# Frontend web (Vue 3)

Cliente Vue 3 que consume `GET /api/books` del backend y lista cada libro con su promedio de calificación.

```bash
npm install
npm run dev
```

La URL de la API se configura en `.env` con `VITE_API_URL` (por defecto `http://127.0.0.1:8000`).

Las instrucciones completas del proyecto (backend, mobile y video) están en el README de la raíz del repositorio.
